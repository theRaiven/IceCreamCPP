# IceCream — фигуры, поверхности и сечения

C++ / Windows / OpenGL 3.3 compatibility. Слева — параметры, в центре — 3D-сцена с осями X/Y/Z, справа — сечение в координатах секущей плоскости u/v.

## Выбор фигуры

В списке доступны Мороженое, Цилиндр, Конус, Шар и Своя поверхность z=f(x,y).

- Мороженое задаётся высотой рожка, радиусом стыка, степенью профиля и высотой шапки. Степень 1 даёт конус, 0.5 — округлый профиль.
- Цилиндр и конус задаются полной высотой и радиусом.
- Шар задаётся радиусом.
- Своя поверхность задаётся формулой двух независимых координат x/y и четырьмя границами прямоугольной области: X от/до, Y от/до.

Поля поддерживают курсор, выделение, Ctrl+A/C/V. Числа размеров принимают точку и запятую; в самой формуле десятичный разделитель — точка. Построить или Enter применяет ввод, Tab переключает видимые поля, Esc отменяет неподтверждённые изменения. Выбор в списке подготавливает поля; геометрия меняется после построения. Неверный ввод сохраняет предыдущую фигуру и результаты.

## Формула z=f(x,y)

В поле после подписи z= вводится, например:

- `x^2 + y^2` — параболоид.
- `sin(x)*cos(y)` — волнистая поверхность.
- `2 - x*y` — седловая поверхность со смещением.
- `sqrt(4-x^2-y^2)` — верхняя полусфера на области, где выражение под корнем неотрицательно.

Можно вставить и полную запись `z=x^2+y^2`. X/Y являются пространственными координатами основания, Z — высотой графика. Это не профиль для вращения: функция использует две независимые переменные.

Поддержаны +, -, *, /, ^, скобки, sqrt, sin, cos, abs, exp, log, min, max, pow, if(условие,a,b), сравнения <, <=, >, >=, константа pi. Умножение пишется явно: `2*x`. Функции sin/cos принимают радианы. Разрешённые границы X/Y: -10..10; длина каждого интервала не меньше 0.1. Высота должна быть конечной и находиться в -50..50 на узлах сетки.

Для вычисления объёма и замкнутого среза график соединяется стенками с горизонтальным нижним основанием. Его высота определяется по минимуму графика: `baseZ=minZ-max(0.25,0.1*(maxZ-minZ))`. Принятая высота основания видна на панели. Так под графиком получается объём с положительной толщиной, в том числе для постоянной функции. Модель не претендует на построение произвольных неявных поверхностей с несколькими Z для одной пары X/Y.

Поверхность дискретизируется сеткой 64×64 ячеек. Объём соответствует замкнутой треугольной сетке. Узкие особенности и разрывы формулы между узлами могут потребовать большей плотности сетки. Для готовых тел вращения используется их профиль; объём интегрируется методом Симпсона.

## Координатная сцена и границы

X — красная ось, Y — зелёная, Z — синяя. На сцене есть сетка, деления, численные подписи и указатель ориентации в углу. Камера вращается перетаскиванием левой кнопкой, перемещается в плоскости экрана перетаскиванием правой кнопкой и масштабируется колесом; сцена подстраивает масштаб под размер новой фигуры.

Пурпурным показаны настоящие границы частей: кольцо соединения рожка и шапки; для поверхности — рёбра перехода графика в стенки и основание. У цилиндра и шара нет искусственного цветового стыка по высоте старого рожка.

На вертикальном или наклонном срезе мороженого пурпурная линия отделяет рожок от шапки. При совпадении плоскости с уровнем стыка показывается полный контур; если срез не пересекает стык, лишняя линия не рисуется. Для поверхности пурпурные точки обозначают пересечения с рёбрами частей объёма. Золотистым показан край самого среза. Координаты u/v относятся к локальной системе секущей плоскости, а не обязательно совпадают с глобальными X/Y/Z.

## Плоскость

Положение опорной точки X/Y/Z задаётся в -20..20, повороты вокруг осей — в -180..180 градусах. Шесть ползунков и числовые поля поддерживают точный ввод; Enter применяет, Esc отменяет. Кнопки XY, XZ и YZ задают ориентацию, сохраняя опорную точку.

Исходная плоскость параллельна XY. Повороты выполняются вокруг мировых осей X, затем Y, затем Z относительно опорной точки. Уравнение: `n·(point-origin)=0`. Перенос вдоль самой плоскости не меняет сечение. Например, у XY высоту среза задаёт Z.

Одна сторона фигуры непрозрачная, другая показана прозрачной оболочкой. Поверхность среза заполнена золотистым; кнопка Прозрачная сторона +/- меняет сторону. Заполнение учитывает вогнутость и отверстия. Площадь считается по сеточному контуру. Изменение плоскости не перестраивает сетку.

В 3D-сцене: зажатая левая кнопка — вращение, зажатая правая — перемещение влево/вправо и вверх/вниз по экрану, колесо — масштаб, C — полный сброс камеры (включая перемещение). Пробел сбрасывает всё к мороженому. Стрелки влево/вправо меняют Z плоскости, вверх/вниз — её угол Y. Размеры применяются кнопкой Построить. Минимальное окно — 1200×800.

## Сборка и проверка

Откройте IceCream.sln в Visual Studio с инструментами C++. Конфигурации Debug/Release, x64. Приложение использует C++20, ядро и тесты — C++17. GLM включён в ThirdParty. GLEW и FreeGLUT ожидаются в C:\vcpkg\installed\x64-windows; путь задаётся VcpkgRoot в IceCream.App.vcxproj.

Запуск: bin/x64/Release/IceCream.App.exe. Проверка: bin/x64/Release/IceCream.Tests.exe. Тесты охватывают геометрию, формулы двух переменных, объёмы и ориентированную замкнутость сеток, контуры, повороты, стыки, совпадающие с плоскостью границы и сохранение состояния после ошибок.

В текущем окружении проверочная Release-сборка выполнена без PDB из-за LNK1101/MSPDB140.DLL. В Developer PowerShell временно установите `$env:_LINK_ = '/DEBUG:NONE /INCREMENTAL:NO'` и выполните `msbuild IceCream.sln /p:Configuration=Release /p:Platform=x64 /p:WholeProgramOptimization=false`. Настройки символов проекта сохранены; для обычной Debug-сборки требуется исправить окружение инструментов отладки.
