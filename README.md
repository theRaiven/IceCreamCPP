# IceCream — формулы, поверхности и сечения

**IceCream** — приложение для построения и исследования трёхмерных математических поверхностей. Позволяет визуализировать функции, строить сечения, вычислять объёмы и площади, настраивать освещение и работать с ограничениями.

Написано на **C++20** с использованием **OpenGL 3.3**. Работает на Windows 10/11 x64.

## Скачать

**[IceCream v0.1.0 Alpha 1 — первый релиз](https://github.com/theRaiven/IceCreamCPP/releases/tag/v0.1.0-alpha.1)**

Доступны два варианта:

- **Setup.exe** — обычный установщик Windows с ярлыками и возможностью удаления программы.
- **Portable.zip** — версия без установки. Достаточно распаковать архив и запустить `IceCream.exe`.

Это первая альфа-версия, поэтому возможны ошибки и проблемы с производительностью.

## Возможности

### Построение поверхностей

Вкладка **«Функции»** позволяет выбрать один из режимов построения.

**Явные функции:**

- Декартовы координаты: `z=f(x,y)`, `x=f(y,z)`, `y=f(x,z)`.
- Цилиндрические и полярные координаты: `z=f(r,phi)`.
- Составные фигуры из нескольких частей (до восьми) со своими формулами и цветами.
- Численное вычисление интегралов с настраиваемыми пределами и порядком интегрирования.

Начальная фигура — мороженое, состоящее из конуса и сферической верхушки:

```text
z=3*sqrt(x^2+y^2)
z=3+sqrt(max(0,1-x^2-y^2))
```

Обе поверхности заданы на единичном диске и соединяются на высоте `z=3`.

Совпадающие границы частей соединяются автоматически. Однако произвольные булевы операции над пересекающимися телами пока не поддерживаются.

**Неявные поверхности:**

Можно задавать уравнения вида `g(x,y,z)=0`. Например, сфера радиуса 3:

```text
x^2+y^2+z^2=9
```

Для построения используется алгоритм **Marching Cubes**. Пользователь задаёт границы по X/Y/Z и плотность сетки.

Поддерживается от 2 до 128 ячеек по каждой оси, но не более 1 000 000 ячеек суммарно.

### Ограничения и обрезка

Поверхности можно обрезать системой математических неравенств:

```text
0<=z<=4-x
y^2<=2*x+2
```

Все условия выполняются одновременно. Их можно вводить через запятую, точку с запятой или с новой строки.

Дополнительно можно включить **отображение поверхностей ограничений**. Они показываются полупрозрачными слоями с отдельными цветами.

Обрезка выполняется по готовой треугольной сетке. При этом новые замыкающие грани не создаются, поэтому результат может оказаться незамкнутым.

### Объёмы, интегралы и площади

Программа поддерживает:

- Численное интегрирование по заданным пределам.
- Вычисление геометрического объёма.
- Вычисление объёма по замкнутой треугольной сетке.
- Построение сечений плоскостью.
- Вычисление площади замкнутых сечений, в том числе с отверстиями.

Если после обрезки сетка оказалась открытой или некорректной, объём не вычисляется. Аналогично, для незамкнутого контура сечения площадь недоступна.

**Точность зависит от разрешения сетки.** Например, для сферы радиуса 3 при сетке 40×40×40 объём составляет примерно 112,72 при теоретическом значении 113,097.

### Трёхмерная сцена

Сцена поддерживает:

- Вращение камеры, перемещение и масштабирование.
- Настраиваемое освещение: направленный, точечный источники и прожектор.
- Тени и сглаживание.
- Настройку цветов поверхностей и сцены.
- Переключение оформления интерфейса.
- Изменение размеров координатных осей и подписей.

Управление камерой:

| Действие | Управление |
|---|---|
| Вращение | ЛКМ |
| Перемещение | ПКМ |
| Масштабирование | Колесо мыши |

### Сечения

Справа от основной сцены находится отдельное окно сечения.

Во вкладке **«Сечение»** можно изменять положение и поворот секущей плоскости, выбирать пресеты XY/XZ/YZ и настраивать отображение.

Сечение строится в локальных координатах плоскости `u/v`.

Управление окном сечения:

- **ЛКМ / ПКМ** — перемещение.
- **Колесо мыши** — масштабирование.
- **СКМ / C** — вписать контур в окно.

Перемещение и масштабирование рисунка не изменяют положение плоскости или результаты вычислений.

### Сохранение фигур

Фигуры можно сохранять и загружать для дальнейшей работы.

Используется формат **JSON**, в котором хранятся параметры построения, формулы, ограничения, границы, цвета и составные части.

## Ограничения текущей версии

IceCream находится в разработке. На данный момент:

- Точность построения и вычислений зависит от плотности сетки.
- Мелкие детали и разрывы функций могут отображаться некорректно.
- Обрезка не создаёт замыкающие поверхности.
- Произвольное объединение и пересечение трёхмерных тел не реализовано.
- Объём открытых или некорректно ориентированных сеток не вычисляется.
- Сложные поверхности могут требовать значительных вычислительных ресурсов.

При ошибке в формуле, границах или ограничениях программа сообщает о проблеме, сохраняя предыдущую построенную фигуру.

## Сборка из исходников

Для сборки необходимы:

- Visual Studio с компонентами разработки на C++.
- Windows SDK.
- C++20.
- vcpkg с библиотеками GLEW и FreeGLUT.
- GLM (также включена в `ThirdParty`).

Зависимости GLEW и FreeGLUT в текущей конфигурации ожидаются в `C:\vcpkg\installed\x64-windows\`.

Откройте `IceCream.sln` в Visual Studio или выполните:

```powershell
MSBuild.exe IceCream.sln /m /p:Configuration=Release /p:Platform=x64
```

Готовая программа находится в:

```text
bin\x64\Release\IceCream.App.exe
```

### Тестирование

В проект включены модульные тесты на Microsoft Native C++ Unit Test Framework.

Проверяются математические операции, геометрия, парсинг выражений, построение поверхностей, обрезка, вычисления и отдельные сценарии работы интерфейса.

```powershell
MSBuild.exe IceCream.sln /m /p:Configuration=Debug /p:Platform=x64
vstest.console.exe x64\Debug\IceCream.Tests.dll /Platform:x64
```
